# 2026-09-21 release validation

This release rewrites the workspace copy in the user's own words, makes the
sidebar behave the same on every screen, stops the project card's hover action
from covering the date, compresses the workspace top bar, and replaces the
materials import panel with a single drop zone that supports reordering and
renaming.

## Copy

`沟通` is now `记录` throughout the interface — 126 replacements across the
workspace, project index, navigation labels, export filenames and view copy.
Mechanism descriptions no longer appear on screen; they live in code comments,
so the interface says what the user gets and the source says how it works.

## Interface

- The workspace no longer forces the sidebar into a 68px icon rail, and no
  longer hides the collapse button. Sidebar width follows the user's own
  preference on every screen, so walking from project management into a
  workspace does not reshape it.
- The project card's hover action was absolutely positioned over the card's
  date and covered it with a white background. It now occupies its own row;
  card height is unchanged.
- The project/record bar went from 92px to 65px. The labels sit beside their
  selects instead of above them, and the selects are sized to their content.
  Content starts 27px higher.
- Materials arrive through one drop zone that accepts recordings, transcripts
  and images together, replacing the four separate import buttons. Materials
  can be dragged into any order or moved with the arrow keys, and renamed in
  place. A reorder that fails on the server rolls back to the stored order.

## Validation

- Production build and sensitive-artifact audit: passed.
- Node tests: 490 passed, zero failures; includes all migrations from an empty
  database and seven new material-shelf contract cases.
- TypeScript and ESLint: passed.
- Reorder and rename were exercised end to end against the local D1: the new
  order and the new filename were both read back from the database, and the
  seeded rows were removed afterwards.

## Deployment scope

- Existing Notique Evidence Workspace Site and its D1/R2 bindings. This is the
  supplementary platform, not app.notiqueai.com.
- Existing GitHub publish-main branch.
- Migration 0019 is included. It adds `assets.sort_order` and backfills it from
  the existing `created_at` order, so the material list reads exactly the same
  immediately after the migration as it did before. It also adds the
  `idx_assets_event_order` index. The column must exist before this build
  serves traffic: the asset list query orders by it.
- Runtime secrets and audience are unchanged.
- Model precision/recall and formal-product integration are not certified by
  these engineering checks.
