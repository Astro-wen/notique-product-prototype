## 文案规则

1. 按钮 2 到 4 字，动词或动宾，不解释后果。
2. 提示一句话，12 字以内，不带句号。
3. 不出现后台、服务器、队列、版本、轮询、系统会。
4. 不安抚：不说没有丢失、仍然保留、不会重复收费。
5. 不用「这条记录」「这项内容」。
6. 空状态一行主文案加一个主按钮。
7. 错误只说发生了什么和能做什么。机制和原因写在代码注释里。
