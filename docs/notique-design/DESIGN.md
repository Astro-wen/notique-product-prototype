# Notique PC 视觉规范

## 1. Visual Theme & Atmosphere

白色阅读面板配浅灰画布，文字和主要操作使用近黑色，蓝色用于选中与定位。正文优先，操作靠近内容。来源为2026-09-30已登录 Notique 项目、时间线和原文页面的实际 DOM、CSS 与计算样式。

## 2. Color

| 用途 | 实际来源值 |
| --- | --- |
| 文字、主按钮 | #0d0d0d |
| 辅助文字 | #59657b |
| 品牌、选中 | #4b75f2 |
| 画布、轻量悬停 | #f5f6f8 |
| 面板 | #ffffff |
| 正文分隔 | #e6e6e8 |
| 项目卡边框 | #e5e7eb |
| 项目卡悬停 | #e5f0ff，边框 #4b75f2 |
| 禁用主按钮 | 底色 #e6e6e8，文字 #a0a0a0 |

完成、待处理和错误继续使用现有语义色，状态文字同时呈现。小字号蓝色文字使用现有 #2d56cf，属于本项目可读性适配。

## 3. Typography

官网正文使用 Noto Sans TC、PingFang TC、Roboto、系统字体及 Emoji 字体的完整回退栈，当前页面未观察到字体下载。正文16px，普通行高24px，原文26px。页面定位标题16px/600，正文一级标题24px/700，二级标题20px/700。主操作小按钮14px/20px，普通控件16px/24px。

## 4. Spacing & Grid

常用间距4、8、12、16px。主按钮高36px、左右16px，普通工具按钮高40px、左右12px。原文块内边距12px 16px。项目卡高89px、最大宽305px、边框2px、圆角16px。按钮圆角6px，排序按钮8px，分享按钮10px。尺寸按具体组件引用。

## 5. Layout & Composition

官网采用固定高度的工作区，正文容器独立滚动，目录与原文按需展开。本项目保持材料、记录、原文依据的现有流程，按主题组织正文，记录、问题、行动和结果在原主题继续呈现。PC验收尺寸为1440×900与1366×768。参考采集实际视口为1867×1344，分别记录。

## 6. Components

共用 NqButton、NqIconButton、NqSurface、NqStatus 和现有 Radix 弹窗。项目卡、目录、原文块和播放器各自映射官网对应结构。原文出处保持蓝色定位，正文操作保留同一排版与间距，主动作由记录当前状态决定。每组显示一次主题标题。

## 7. Motion & Interaction

沿用官网 transition-colors 和轻量背景变化。键盘焦点使用清晰边框，已有 Radix 焦点管理继续复用。保存、加载、禁用和失败复用同一组件状态。复制等待当前保存队列完成，成功后呈现回执，失败保留输入。

## 8. Voice & Brand

界面用直接动词，例如确认这条、改一下、补答案、补结果、复制记录。重点内容负责解释，标签只表达必要状态。MCP入口说明连接已有结果、读取原话、查看当前版本和撤销连接，费用说明与后台生成分开。

## 9. Anti-patterns

避免用新的字体和颜色替换已经核实的官网值。避免统一所有组件圆角而抹平实际差异。避免把信息按类型拆成多份清单，或用重复标签代替主题分组。避免按钮外观相同但保存行为各异。避免把扫描成功写成任务完成。
