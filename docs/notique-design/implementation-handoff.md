# 前端实现承接

先统一字体与画布，再依次替换共用按钮、项目卡、阅读目录、原文块和弹窗状态。每项引用 DESIGN.md 中对应组件值，来源记录在视觉库页面。

主题分组、批阅、答案、行动结果和复制继续调用现有领域接口。视觉替换完成后，用桌面1440×900及笔记本1366×768执行实际流程，检查普通、悬停、焦点、加载、禁用与失败。官网参考值与本项目适配值在 tokens.json分别记录。

验收材料包括页面截图、实际点击路径和来源对照表。后台离页验收期间采集参考并在本地复用组件，生产发布安排在自然观察终态之后。发布沿用main和现有Sites项目，保存版本与GitHub源码SHA一致。
