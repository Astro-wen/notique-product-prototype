## 2026-09-29 主页面真实联调

### 已接入的用户路径

本次重点默认打开同页记录，原文和材料仍在原工作区。记录读取由 Query 管理，保存经 Service 调用真实 V2 接口。来源按需读取原有证据接口，复制显式限定当前沟通。

1. 直接打开完整草稿并复制，保留 AI 草稿标识。
2. 查看原话，就地修改一条，保存后刷新仍是新版本，其余草稿继续保留。
3. 采纳行动、完成行动、补入答案，答案替换问题原来的位置。
4. 修正结果与撤回结果，更新记录中的答案，行动完成状态独立保留。
5. 直接回答问题，已有答案时选择替代或并存。并存的适用情况同时进入页面和导出。
6. 服务器已保存但回执丢失时沿用原请求与原幂等键重试。另一个页面修改后保留本地输入，展示当前内容，用户核对后再保存。
7. 暂缓和恢复处理保存个人进度，保留草稿，既有内容版本保持稳定，也不生成新概要任务。

### 截图发现与修复

- 修正报价时，重点显示十三万而行动说明保留十二万。现在自动来自答案的说明随答案一起更新，用户另写的执行备注单独保留。
- 手机行动行的操作按钮把正文挤成竖排。手机端改为正文一行、操作另起一行，并增加正文宽度断言。修复后重新检查截图。
- 普通重点使用连续行，减少每条嵌套卡片的边框和留白。
- 补入的答案使用更新答案入口，避免绕到普通纠错后因答案关系被阻止。
- 两个答案并存时，适用条件曾只保存在关系中。现在 Bullet.applicability 传到页面与复制记录。
- 编辑中切换记录、材料、原文或主导航会保留当前输入并提示保存或取消。刷新离开仍使用浏览器未保存提醒。
