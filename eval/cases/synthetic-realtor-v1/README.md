# Morgan 家庭购房旅程测试案例

这是一个完全合成、已经脱敏的开发评测案例。人物、对话、房源、金额、学校选择和时间均不对应真实客户。

## 核心故事

同一组买家经历一次需求访谈、两次看房和一次出价策略电话。四次沟通中，预算从无法分辨的 115 万或 150 万美元，先确认成 115 万美元，后来由两位买家共同提高到 128 万美元。住房偏好从有年代感的老房，变成 2000 年以后或主要系统已经翻新的房屋。买家还纠正了“in-law unit”的含义，明确要求有独立入口且许可完整的 ADU。

案例同时保留了两位共同决策者对 HOA 的冲突、持续三次没有解决的学区问题、两次以上带有放弃方案和原因的购房决定，以及在不同沟通中反复出现但没有变化的卧室数、通勤、安静街道和 ADU 要求。

## 建议检查

1. 系统不能把第一次录音中的价格直接判断成 115 万或 150 万美元，必须提出澄清问题。
2. 第二次沟通确认 115 万美元后，第四次沟通应把当前预算更新为 128 万美元，旧预算仍留在历史中。
3. “in-law unit”应被纠正成“有独立入口的合法 ADU”，不能继续使用含义不清的旧条件。
4. Redwood Avenue 被放弃的原因是持续交通噪声。Harbor Court 先成为首选，后来因不在 Palo Alto Unified 而被放弃。
5. Lena 可以接受每月 350 美元 HOA，与 Evan 完全拒绝 HOA 的说法发生冲突。第四次沟通把两人的共同标准定为每月不超过 300 美元并附带条件。
6. 三卧室、45 分钟通勤等未变化事实应记录为再次出现，不应建立重复的当前事实。
7. 所有结论都应指向原始逐字稿片段。这个案例没有图片，专门用于验证跨事件文字证据、增量分类、关系和人工确认流程。

## 文件说明

- `manifest.json` 定义一个 Project、四次 Event、逐字稿路径和证据别名。
- `ground-truth.json` 保存原子化标准事实、精确片段、分类、歧义和跨 Event 关系。
- `transcripts/` 保存四次带说话人和时间点的合成逐字稿。

Ground Truth 目前由单人起草，尚未经过两位标注者独立复核。它不是盲测集，也不是真实用户数据。这个单场景案例可以用于开发评测和回归测试，不能单独证明产品概念成立。
